# STM32F103C8T6 流水灯学习笔记

## 一、功能需求

红=A0、黄=A1、蓝=A2、绿=A3 单灯循环流动；走到 A3 停 1 秒回 A0；PC13 心跳灯 500ms 翻转；共阳 LED 低电平点亮。

## 二、接线与极性

红→A0、黄→A1、蓝→A2、绿→A3；

共阳接法，低电平点亮：点亮 = RESET，熄灭 = SET。

## 三、两种实现

阻塞式：`HAL_Delay()` 死等延时，按节拍推进；

非阻塞式：`HAL_GetTick()` 时间戳差值判断，CPU 不空转。

## 四、核心代码

初始化：A0\~A3 + PC13 推挽输出，先全灭再点亮红。

阻塞版：

```c
while (1) {
    HAL_Delay(100);
    tick++;
    if (pause) {
        if (tick - pause_tick >= 10) {   // 停 1 秒
            pause = 0; idx = 0;
            HAL_GPIO_WritePin(GPIOA, LED_ALL, GPIO_PIN_SET);
            HAL_GPIO_WritePin(GPIOA, leds[0], GPIO_PIN_RESET);
        }
    } else if (tick % 2 == 0) {          // 每 200ms 走一步
        if (idx == 3) { pause = 1; pause_tick = tick; }
        else {
            idx++;
            HAL_GPIO_WritePin(GPIOA, LED_ALL, GPIO_PIN_SET);
            HAL_GPIO_WritePin(GPIOA, leds[idx], GPIO_PIN_RESET);
        }
    }
    if (tick % 5 == 0)                   // 每 500ms 心跳
        HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
}
```

非阻塞版：

```c
while (1) {
    now = HAL_GetTick();
    if (pause) {
        if (now - pause_t0 >= 1000) {    // 停 1 秒
            pause = 0; idx = 0;
            HAL_GPIO_WritePin(GPIOA, LED_ALL, GPIO_PIN_SET);
            HAL_GPIO_WritePin(GPIOA, leds[0], GPIO_PIN_RESET);
            last_step = now;
        }
    } else if (now - last_step >= 200) { // 每 200ms 走一步
        last_step = now;
        if (idx == 3) { pause = 1; pause_t0 = now; }
        else {
            idx++;
            HAL_GPIO_WritePin(GPIOA, LED_ALL, GPIO_PIN_SET);
            HAL_GPIO_WritePin(GPIOA, leds[idx], GPIO_PIN_RESET);
        }
    }
    if (now - last_heart >= 500) {       // 每 500ms 心跳
        last_heart = now;
        HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
    }
}
```

## 五、代码逻辑拆解

1. 点灯：靠 `HAL_GPIO_WritePin`，低电平(RESET)=亮、高电平(SET)=灭。换灯套路是「先全灭，再点亮目标」。

2. 顺序：靠 `leds[]` 数组 + `idx` 指针。
   - `leds[4]` = 红黄蓝绿的排队；
   - `idx` = 指针，指到谁亮谁；
   - `idx` 从 0→1→2→3 递增，`leds[idx]` 就依次是红黄蓝绿。

3. 节奏：
   - 阻塞版：`HAL_Delay(100)` 卡 100ms，`tick++` 数圈，`tick % 2 == 0` 即每 200ms 走一步；
   - 非阻塞版：`HAL_GetTick()` 读毫秒，`now - last >= 200` 判断到点。

4. `tick` 与 `idx` 是两回事：tick 记时间(什么时候动)，idx 记位置(动到哪个灯)。

5. 时间戳原理：记下上次时间，每圈算「现在 - 上次」，够阈值就干活，再把「上次」更新成「现在」。

## 六、小结

1. 核心是「全灭 + 点亮当前位」的循环推进；
2. 共阳 LED 低电平点亮，极性写反现象相反；
3. 阻塞式简单但占 CPU，非阻塞式易扩展。
